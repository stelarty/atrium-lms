## 🔄 Логика Работы

### Загрузка Данных
```
При загрузке страницы:
  GET /api/edspace/onboarding/
    ↓
  Если onboarding_done: false
    ↓
  Показываем widget с текущим прогрессом
```

### Закрытие Онбординга
```
Пользователь кликает крестик
  ↓
PATCH /api/edspace/onboarding/ с {"is_seen": true}
  ↓
Widget скрывается
  ↓
При следующей загрузке widget не показывается
```

## 🧪 Тестирование

Готово к тестированию. Для проверки различных сценариев:

1. **Онбординг в процессе:**
   - Обновить в БД: `onboarding_done: false` с шагами
   - Ожидаемо: widget с задачами и кнопкой развертывания

2. **Завершен, не просмотрено:**
   - Обновить в БД: `onboarding_done: true, is_seen: false`
   - Ожидаемо: widget с крестиком (без задач)
   - После клика на крестик: widget исчезает

3. **Полностью завершен:**
   - Обновить в БД: `onboarding_done: true, is_seen: true`
   - Ожидаемо: widget не видимый

Подробнее см. `docs/TESTING_ONBOARDING.md`
