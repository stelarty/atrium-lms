# BaseCheckbox

**BaseCheckbox** — атомарный чекбокс для выбора булевого значения.

Используется в:
- dropdown
- формах
- фильтрах
- списках

---

## Props

| Название   | Тип       | Описание                  |
|------------|-----------|---------------------------|
| `checked`  | `boolean` | Состояние чекбокса        |
| `disabled` | `boolean` | Блокировка взаимодействия |

---

## Emits

| Событие          | Аргументы | Описание           |
|------------------|-----------|--------------------|
| `update:checked` | boolean   | Изменение значения |

---

## Состояния

- default
- checked
- pressed
- disabled

---

## Особенности

- Размер: **16×16**
- Иконка галочки — `UiIcon name="check"`
- Pressed реализован через `:active`
- Не содержит бизнес-логики
