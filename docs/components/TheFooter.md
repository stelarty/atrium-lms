# Footer

**Footer** — уникальный компонент нижней панели приложения в **LMS Атриум**.

Используется для отображения брендинга, навигационных ссылок и копирайта.  
Компонент существует в единственном экземпляре на странице.

---

## Особенности

- Префикс `The` используется для имени файла компонента
- Закреплён внизу страницы (`margin-top: auto`)
- Содержит брендинг, быструю навигацию и копирайт
- Использует глобальный контейнер `.container` из `styles/layout/_container.scss`
- Реализует адаптивную сетку через media queries
- Не хранит внутреннее состояние (stateless)

|------|----------|

## Примеры использования

### Базовый

```vue
<template>
  <Footer />
</template>
```

### В MainLayout

```vue
<script setup lang="ts">
import Footer from '@/components/layouts/Footer.vue'
</script>

<template>
  <footer class="main-layout__footer">
    <slot name="footer" />
    <Footer v-if="!$slots.footer" />
  </footer>
</template>
```

### С кастомными ссылками

```vue
<script setup lang="ts">
import Footer from '@/components/layouts/Footer.vue'
</script>

<template>
  <Footer>
    <template #links>
      <a href="/help">Помощь</a>
      <a href="/careers">Карьера</a>
    </template>
  </Footer>
</template>
```

## Архитектурные принципы

- Компонент не содержит бизнес-логики или store
- Не управляет своим состоянием (stateless)
- Все стили scoped, импортируются из отдельного SCSS файла
- Использует семантический тег `<footer>` для доступности
- Соответствует стандартам `workflow.md` §1.2 (префикс `The`)
- Соответствует стандартам `styles.md` §7 (БЭМ нотация)
