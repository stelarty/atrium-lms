# BaseSwitcher

Универсальный переключатель, предназначенный для включения/выключения опций в интерфейсе.

## Использование

```vue
<BaseSwitcher
  v-model="isActive"
  label="Включить уведомления"
  hint="Опциональное поясняющее сообщение"
/>
```

## Свойства

| Свойство     | Описание                                 | Тип      | По умолчанию |
|--------------|------------------------------------------|----------|--------------|
| `modelValue` | Текущее состояние переключателя         | `boolean`| `false`      |
| `label`      | Основной текст метки                     | `string` | `''`         |
| `hint`       | Вспомогательный текст подсказки          | `string` | `''`         |

## События

| Событие               | Описание                                         |
|-----------------------|--------------------------------------------------|
| `update:model-value`  | Генерируется при изменении состояния переключателя |

## Состояния

- **Default**: невыбранное состояние
- **Checked**: выбранное состояние
- **Pressed**: состояние при нажатии (визуальная обратная связь)
- **Disabled**: отключенное состояние (поддерживается через стили родителя)

## Стили

Стили переключателя реализованы с использованием SCSS переменных проекта:
- `$surface-default-primary`, `$surface-default-disabled` — цвета фона
- `$text-default-primary`, `$text-default-secondary` — цвета текста
- `$m1`, `$m2`, `$m4` — размеры отступов

Переключатель имеет плавные переходы при изменении состояния и корректно отображается на всех устройствах.
