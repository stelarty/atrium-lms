# Changelog — LMS Атриум

Все заметные изменения в проекте фиксируются здесь.

Файл ведется по принципу **Keep a Changelog** и с учетом **семантического версионирования (SemVer)**.

---

## Правила ведения changelog

1. **Фиксируем все изменения, влияющие на проект:**

   * Добавление новых функций, страниц, компонентов, store, composables
   * Изменения существующих компонентов, API, стилей
   * Исправление багов
   * Любые изменения, влияющие на UI или UX

2. **Структура версии:**

   ```
   ## [X.Y.Z] - ДАТА
   ### Added
   ### Changed
   ### Fixed
   ```

   * **X (Major)** — глобальные изменения, несовместимые с прошлой версией
   * **Y (Minor)** — новые функции, совместимые с предыдущей версией
   * **Z (Patch)** — исправления багов и мелкие правки

3. **Unreleased**

   * Все изменения до выпуска новой версии пишутся в раздел `## [Unreleased]`.
   * После релиза они переносятся в конкретную версию с датой, а `Unreleased` очищается для новых изменений.

4. **Правила заполнения:**

   * Каждое изменение кратко и понятно описывается
   * Используем категории:

     * `Added` — новое
     * `Changed` — изменено
     * `Fixed` — исправлено
   * Не пишем внутренние заметки или личные комментарии
